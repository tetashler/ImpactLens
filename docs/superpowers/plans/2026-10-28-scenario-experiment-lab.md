# Evidence-grounded Scenario Experiment Lab

**Goal:** Configure a counterfactual, inspect source-supported context, save immutable experiments and compare assumptions without inventing stakeholder outcomes.

**Architecture:** Browser-safe versioned evidence and experiment contracts; one bounded replay endpoint; an independently testable external-store controller; a General inspector panel; a read-only projection into the existing Knowledge Graph. Existing MRT/AAC engines, planning contracts, map ownership, credentials and local-review building assets remain unchanged. The user's detailed Phase 7E specification is the approved scope; no Git mutations are authorised.

**Design:** Preserve the current navy/teal palette and typography. Use a working notebook layout: configuration and evidence, followed by a compact snapshot history and a field-level comparison. A wider inspector is appropriate for non-geographic research; retain the map and collapse into a stacked sheet on mobile. Highlight actual changed assumptions, never fabricated economic forecasts.

## Review focus

1. An old asynchronous reply must not bind to a new question/geometry/assumption revision, even after A → B → A.
2. Imported records and copied evidence are untrusted: verify support, identities, bounded shapes and safe links; freeze detached snapshots.
3. Evidence replay dates are historical source-verification dates, not newly fetched source dates. Missing evidence stays unknown.
4. Saved configurations are not stakeholder runs; comparisons describe configuration/evidence changes only.
5. The existing graph, map, citizens and calculated-result bindings retain their ownership and provenance. No renderer internals or simulation algorithms need changes.

Final validation: 457 Node tests / 19 GIS tests, six CLIs, application/strict types, build and actual Playwright acceptance passed. See the implementation report for boundaries and evidence. Git changes remain unstaged/uncommitted.
