## Architecture

- Keep the Phase 7H question/context owner and existing calculator confirmation gates. Standard Start requests live inference; an explicitly labelled ASEAN demonstration invokes the retained scripted path. Unconfigured/failed live inference never silently substitutes scripted output.
- Add a browser-safe strict inference/status contract and a separate v2 request session. Retain the unchanged v1 parser. Validate exact input/attempt/run identities, fixed serving model/provider, diagnostic records/aggregates and nullable usage.
- Use one explicit context-to-domain boundary: narrow positive Singapore ASEAN withdrawal; clear hypothetical import-goods-tax intent; MRT-specific intent with confirmed geographic context. Other questions remain not simulated or use their separately supported calculator. Scope alone selects nothing.
- Research/experiment snapshots remain frozen. Live executions retain their originating validated snapshot and separately identified preset configuration. The source handoff is never relabelled as executed. Preserve actual ASEAN replay references; generic/MRT presets never invent sources or calculated values.
- Extend the existing controller with explicit live/scripted dispatch, remaining-time deadlines, accepted partial/failed/cancelled records, diagnostics and four immutable archives. Preserve monotonic revision/attempt/geometry guards after every await. User cancellation still rejects late results.
- Keep one map/citizen owner and one graph renderer. Project accepted live records with exact source/run lineage into a standalone graph; never relabel old calculator identities. Reports render actual selected records and diagnostics, with accepted native calculator DTOs kept distinct.
- Read-only provider status shows configuration and enablement, never an invented connection verification. Fixed DeepSeek/OpenRouter/DigitalOcean routing and disabled fallback remain server-only.
