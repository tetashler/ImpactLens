# Scenario experiment and stakeholder integration plan

**Goal:** Execute two immutable ASEAN experiments through the existing sequential stakeholder engine and compare their configurations, evidence and recorded runs.

**Architecture:** Phase 7E remains the configuration/evidence owner. An async bridge validates its full frozen handoff and derives the bounded Phase 7D request. A separately validated linked record retains that handoff, the original saved experiment and the actual run. The execution panel edits only execution options. Saved-run graph projections use the saved experiment identity and a standalone base, preserving the current MRT/AAC graph separately.

**Stack:** Existing Next.js/React/TypeScript, Node API routes and Cytoscape. No dependency or infrastructure addition. The user's complete integration brief is the implementation specification.

## Constraints and verification boundaries

- No Git mutations, public deployment, paid provider requests or changes to raw inputs/model formulas.
- Keep all source worktree files untouched; use the checksum-verified external main backup.
- Preserve full Phase 7E identities and its `not-executed` source execution boundary.
- Reject unsupported input configurations and nonrepresentable bounds rather than truncating or guessing.
- Keep source replays historical; scripted participants fictional and qualitative.
- Preserve one map, citizen owner and graph renderer; current engine graphs stay independent of archives.
- Run preparation, full tests and builds sequentially on Windows.

## Review focus

1. A saved experiment is never mutated or substituted with a local approximation when execution starts.
2. Old completed runs remain inspectable as archives but cannot attach to a new draft or current engine graph.
3. A source citation does not promote a fictional interpretation into a fact or forecast.
4. Deferred conversion/import/graph work is guarded as well as network execution; abort alone is insufficient.
5. Import/export retain full original identities and reject collisions or mismatched linked records.

The final integration report records actual results, remaining limits, maintained paths and the unexecuted Git proposal. No commit or synchronisation step is executed in this assignment.
