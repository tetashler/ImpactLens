## Delivered improvement and boundaries

The isolated adapter demonstrably loads a geographically selected subset into the **existing** MapLibre map, instead of fetching/parsing every footprint on first neighbourhood entry. It improves loading, preserves whole footprints across partition edges and adds official URA landmark/institutional coverage in some views. It does not solve Singapore's missing private/industrial inventory or measured-height gap. It is a selectable alternative catalogue, **not an automatic HDB replacement or a merged superset**. No original component or calculation changed; Terminal 3 must apply the documented lifecycle/toggle/status hooks when integrating with Phase 7A.1.

The [source audit](PHASE7C_BUILDING_SOURCE_AUDIT.md) contains acquisition/licence evidence, SHA-256 checksums, geometry/height caveats and seven-district inventory comparisons. The [integration guide](PHASE7C_TERMINAL3_INTEGRATION_GUIDE.md) lists exact files, imports, ownership, preparation, conflict risks and acceptance steps.

Official URA GeoJSON: **52,624,128 bytes**, September 2025 reference, catalogue update December 2025, accessed October 2026. **14,333 raw records → 14,212 prepared features**, 8 degenerate-ring exclusions, 113 exact original-geometry duplicates; category conflicts and five rounded near-overlaps remain reported. All raw bytes stay separate/unchanged. A pinned checksum and dated acquisition receipt prevent silent reference-date drift. No raw or generated bulk data is staged/tracked.

Derived catalogue: **99 chunks, 25,218,095 referenced GeoJSON bytes, 26,790-byte manifest**, maximum chunk **1,376,161 bytes**. One source/layer handles three fetches concurrently, ≤32/12 MB selected chunks and a 12 MB serialized-input cache; these are input budgets, not actual JS/GPU memory caps. Failed chunks are explicit incomplete/error states. Content hashes identify cached assets. No vector-tile server, GIS database or new dependency was introduced. Existing static GeoJSON preparation remains unchanged.

Heights remain **12 m illustrative**, with no random variation or footprint-area inference. Typed direct-source and floor-derived policies are available for future verified attributes, but neither was applied. Slight palette/opacity/vertical-gradient adjustments clarify the existing geometry; actual land, streets, rail, AAC and citizen coordinates are unchanged. No global lighting/terrain/camera change. Source codes are retained without inventing occupancy meanings.

## Phase 7C.1 addendum — 28 October 2026

Phase 7C.1 adds an optional offline Overture acquisition and Shapely/GEOS preparation pipeline, retaining the original HDB and URA inputs. Indexed deterministic overlap selection emits one HDB/URA/Overture view with original source identities. The browser contract now supports a source registry and `local-review-only` distribution flag; the adapter retains one source/layer, bounded viewport loading and its existing lifecycle. Source-specific chunks preserve provenance, while source properties and exclusion/conflation audits stay in ignored sidecars.

Visual review found that suppressing every non-minor overlap removed distinct shared-roof HDB blocks and a larger hospital roof. The corrected policy suppresses equivalent roofs or candidates covered at least 50% by the union of earlier retained blockers; other conflicting roofs survive with explicit residual-overlap records. The real four-block fixture now retains all four, and the targeted Python suite passed 19 tests. These focused results do not replace final catalogue/browser validation. Opaque extrusion is the revised visual policy for alpha-stacking artefacts; it does not remove residual geometry overlap or establish source identity.

Python dependencies are isolated in `tmp/phase7c1/venv`; no new Next.js runtime dependency is needed. Default output stays under `tmp/phase7c1/derived`; only explicit `--preview` copies validated chunks and `unified-manifest.json` to local public assets. The loopback guard limits accidental preview use, and the licensing decision still forbids treating a localhost public demo as cleared. The earlier URA-only manifest remains separate.
