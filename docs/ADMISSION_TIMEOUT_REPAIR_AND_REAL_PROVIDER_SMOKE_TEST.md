## Stage A — Investigation and repair

The original structured transport started its model-response timeout before calling the task guard. The guard could then perform expensive immutable population/selection verification inside that timer. It could also reach reservation without a fresh cancellation check. A timeout therefore did not establish whether a request had actually reached native fetch.

The narrow repair introduces a trusted server-process capability, `impactlens.inference-admission-v1`, used only for social inference. It provides bounded local preparation and a one-use exact-body receipt. The existing 30-second provider-response timeout begins after successful preparation and reservation. Local preparation is limited to 60 seconds; the whole operation is bounded by local plus provider limits and the earlier absolute task deadline. Explicit injected fetchers remain isolated. Default Next.js-wrapped fetch can use the process registration because Next's wrapper does not preserve the fetch function's symbol properties.

The actual task server prewarms the immutable selection proof before listening. Every social preparation still verifies current accepted context, actor, run, scenario, selection and source identity. A warm proof is never permission to reuse a changed identity. Immediately before native social dispatch, the guard checks exact request/permit binding, cancellation, deadline, build and verified file identities without re-reading large dataset/proof bodies. Full byte/hash verification remains in local preparation. Symlink replacement and changed file stamps fail closed.

The new task ledger uses `phased-provider-admission-v1`. Reservations are durable before native dispatch. A cancellation after reservation can be reconciled to zero only through durable, authoritative proof that native invocation did not occur. The proof also reaches the application usage record, including a reproduced race during the durable dispatch-authorization write. Once native invocation may have happened, cost remains conservatively unknown unless authoritative returned usage is available. No automatic retry is added; a cancelled reservation does not recycle request identity or grant.

The established inference record format and accepted-world journal format are unchanged. Legacy inference without the new server capability retains its previous execution path. Accepted V7 decisions continue to use the frozen original policies.
